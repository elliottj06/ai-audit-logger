Zero-code integration
Instead of changing your application code, point your AI client to these proxy URLs. Every call gets logged automatically — no SDK installation required.

Configure your API keys in the , then use the URLs below.
OpenAI OpenAI Proxy
Change base_url in your OpenAI client:
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8000/proxy/openai/v1",
    api_key="your-openai-key"  # or leave empty if key is set in dashboard
)

# All calls now logged — no other changes needed
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello!"}]
)
Proxy URL: http://localhost:8000/proxy/openai/v1 📋
Anthropic Anthropic Proxy
Change base_url in your Anthropic client:
from anthropic import Anthropic

client = Anthropic(
    base_url="http://localhost:8000/proxy/anthropic",
    api_key="your-anthropic-key"  # or leave empty if key is set in dashboard
)

response = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Hello!"}]
)
Proxy URL: http://localhost:8000/proxy/anthropic 📋
Gemini Google Gemini Proxy
Use the proxy URL with the Google AI Python SDK:
import google.generativeai as genai
from ai_audit_logger import wrap

genai.configure(api_key="your-gemini-key")
model = wrap(genai.GenerativeModel("gemini-1.5-flash"))

response = model.generate_content("Hello!")

# Or direct HTTP (no SDK needed):
# POST http://localhost:8000/proxy/gemini/v1beta/models/gemini-1.5-flash:generateContent
Proxy base: http://localhost:8000/proxy/gemini 📋
Tag your calls (optional headers)
Add these headers to any request to tag logs without touching your app code:
x-app-name: my-chatbot
x-user-id: user-123
x-session-id: session-abc
Security notice
Keys saved here are stored on your server only in a local config file. They are never logged in the audit system and never sent to third parties. For production deployments, prefer setting keys as environment variables (OPENAI_API_KEY, ANTHROPIC_API_KEY, GEMINI_API_KEY). Always use HTTPS in production.

Slack Alerts
Get notified when a single call costs more than a threshold or hourly spend spikes. Set SLACK_WEBHOOK_URL in your .env file and restart the server. 
SLACK_WEBHOOK_URL=https://hooks.slack.com/services/...
ALERT_COST_PER_CALL=0.50
ALERT_HOURLY_COST=5.00
